# Gr84phWar

A port of the game [*Graphwar*](https://github.com/catabriga/graphwar), but for calculators like the TI-84 Plus CE (or similar)!

> To specify, this is a port / recreation of Graphwar 1. If you wanted a recreation of the newer game, Graphwar 2, tough luck, buddy.

### Status

Currently the homescreen & the settings menu for (soon to be added) main game have been implemented. The main game has still not been added.

## Controls

### General

| Key(s) | Action |
|---|---|
| Enter / Second | Executes the selected action |
| Clear | Exits the program from anywhere |

### Homescreen

| Key(s) | Action |
|---|---|
| Up | Move selected action up |
| Down | Move selected action down |

### Game Settings

| Key(s) | Action |
|---|---|
| `Y=` | Adds a team member to the left team |
| Window | Removes a team member from the left team |
| Zoom | Adds a team member to the right team |
| Trace | Removes a team member from the right team |
| Graph | Starts the game |

> Graph obviously still doesn't start the game, instead, it exits since the main game hasn't been implemented yet. Obviously.
